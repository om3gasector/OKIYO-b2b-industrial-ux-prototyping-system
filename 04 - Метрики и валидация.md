## Ключевые метрики (Было vs Стало)

| Метрика | Было (Konvels As-Is) | Стало (OKIYO Prototype) |
| :--- | :--- | :--- |
| Клики до каталога | 3–5 | 1 |
| Клики до заявки (RFQ) | 5+ | 1-2 |
| Время до элементов доверия | Не сканируется | <5 сек |
| Доступность тех. данных | Только PDF (скачать) | HTML Tabs + Download (мгновенно) |
| Наполнение каталога | Текст/Список | 25 интерактивных карточек с фильтрацией |

## 1. Qualitative Validation (Usability Testing)

##### Методология
*   **Тип:** Moderated Usability Test (Face-to-face).
*   **Участник:** 1 человек (Мужчина, 28 лет). Роль: Инженер.
*   **Контекст:** Не владеет английским (B2+). Проверка интуитивности визуального языка.
*   **Задача:** Найти прибор, изучить характеристики, скачать документацию.
## Сценарий и Наблюдения

| Этап              | Поведение                                                                     | Инсайт / Вывод                                                                |
| :---------------- | :---------------------------------------------------------------------------- | :---------------------------------------------------------------------------- |
| Навигация         | Пауза ~5 сек у сайдбара (англ. термины). Преодолен методом тыка <8 сек.       | Визуальная структура (чекбоксы/радио) компенсирует языковой барьер.           |
| Ориентация        | Быстрая адаптация без возврата на главную.                                    | Интерфейс работает как «универсальная схема».                                 |
| Изучение продукта | Сразу переключился на `Documentation`, игнорируя Description.                 | Подтверждена гипотеза Three-Buyer Blueprint: инженеру нужны факты и точность. |
| Конверсия         | Заполнил форму за ~25 сек. Оценил валидацию («понятно, почему кнопка серая»). | Эмуляция валидации считывается как системный ответ, а не баг.                 |
##### Ключевые выводы
1.  **Интуитивность > Локализация:** Успешное выполнение задачи без знания языка доказывает верность IA.
2.  **Эффективность Pill-фильтров:** Быстрая ориентация подтверждает приоритет горизонтальной навигации.
3.  **Зона роста:** Добавить тултипы/локализацию для сайдбара, чтобы сократить адаптацию с 5 до 0 сек.

## 2. Quantitative Validation Plan (Maze / PathWay)

##### Цели тестирования
*   Проверить эффективность 3 точек входа.
*   Измерить Time on Task и выявить слепые зоны.
##### Ключевые метрики (KPIs)

| Метрика | Baseline (Konvels) | Target (OKIYO) | Инструмент |
| :--- | :--- | :--- | :--- |
| Time to Catalog | > 2 мин | < 15 сек | Maze Timer |
| Task Success Rate | Низкая | > 85% | Mission Completion |
| Misclick Rate | Высокий | < 5% | Click Map |
| Form Abandonment | Высокий | Снижение на 30% | Interaction Tracking |

### Миссии для Maze (Tasks)

1.  Homepage Scan (Heatmap): «Просмотрите главную страницу 20-60 секунд. О чем компания?»
    *   *Цель:* Проверить внимание к Hero CTA, Industry Block и Trust Signals.
2.  Catalog Navigation (Directed): «Найдите плотномеры (Density meters), изучите характеристики и скачайте PDF.»
    *   *Success:* Клик по Download PDF.
3.  Industry Shortcut (Directed): «Вы директор завода. Найдите оборудование для химической отрасли БЕЗ использования верхнего меню.»
    *   *Success:* Клик по элементу Metallurgy в блоке Industries.
4.  Form Stress Test (Directed): «Вы хотите запросить коммерческое предложение на прибор. Попробуйте заполнить форму "Submit a Request". Затем заполните только телефон.»
    *   *Success:* Осознание причины неактивности кнопки.
5.  Sertificate scan (Heatmap): «# Найдите информацию о сертификатах и стандартах качества компании, ознакомтесь с ними»
	*   *Success:* Клип по View details in sertificate cards
6.  Menu-less Nav (Heatmap): «Вернитесь к полному каталогу БЕЗ верхнего меню.»
    *   *Success:* Клик по Pills, Breadcrumbs или Логотипу.
### Блоки вопросов (Follow-up Questions)
После миссии №2 (Каталог):
*   Scale (1-5): «Насколько легко было найти нужный прибор?»
*   MC: «Что помогло быстрее всего?» (Sidebar / Pills / Cards / Search)
*   Open: «Были ли моменты непонимания при исчезновении/появлении карточек?»
После миссии №5 (Форма):
*   Yes/No: «Понятно ли было, почему кнопка была неактивна?»
*   Scale (1-5): «Насколько форма выглядела надежной?»
Финальный опрос:
*   MC: «Кем вы себя чувствовали?» (Инженер / Закупщик / Директор / Тестировщик)
*   Open: «Если бы вы могли изменить ОДНУ вещь, что бы это было?»
## 3. Benchmarking

| Параметр | Konvels (As-Is) | Metran / Owen | Chevron (Ref) | OKIYO (To-Be) | Комментарий |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Поиск оборудования | Текст в меню | Перегруженный каталог | Отраслевой подход | **3 точки входа + Smart Grid** | Скорость + глубина |
| Тех. информация | Только PDF | Смешанный формат | Case studies + Specs | **HTML Tabs + Download** | Мгновенный доступ к данным |
| Доверие (Trust) | Отсутствует | Серты в футере | Global logos | **Dedicated Trust Block** | Вынесено на главный экран |
| Конверсия (CTA) | Форма контактов | Размытые призывы | Четкие RFQ paths | **Multi-touch CTA System** | Валидация в реальном времени |
| Визуальный язык | Устаревший | Сухой функционал | Editorial | **Industrial Clean + Data** | Баланс эстетики и точности |

**Вывод:** OKIYO занимает нишу "Modern Industrial Utility", беря глубину от Owen/Metran и упаковывая её в визуальный язык уровня Chevron/AWS.
